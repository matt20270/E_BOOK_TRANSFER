# X4 Pro Reader Studio (웹 v0.3.0)

설치 없이 브라우저에서 쓰는 전자책 변환·TXT 정리 사이트입니다. 서버가 없고 **파일은 기기 밖으로 나가지 않습니다.**

## 할 수 있는 일
- **PDF → EPUB**: 글자가 있는 PDF는 글자를 그대로 가져오고, 스캔한 쪽은 브라우저 안에서 글자 인식(OCR, 한국어+영어)을 합니다. 쪽 번호·머리말 자동 제거, 제목으로 목차 만들기, 쪽마다 "글 / 쪽 이미지 / 글+이미지 / 제외" 선택, 기울어진 글자 다시 인식(전체 옵션 또는 쪽별 버튼), 인식이 불확실한 단어 노란색 표시 후 직접 수정.
- **TXT 정리**: 줄바꿈이 엉킨 TXT를 문단으로 복원 (UTF-8/CP949 등 저장).

## GitHub Pages에 올리는 방법 (터미널 필요 없음)
1. GitHub에 로그인하고 **New repository**로 새 저장소를 만듭니다 (Public, 이름 예: `x4-reader`).
2. 저장소 화면에서 **uploading an existing file**을 누릅니다.
3. 이 ZIP을 풀고, **폴더 안으로 들어가서** 전체 선택(Cmd+A)한 뒤 끌어다 놓습니다. (폴더째 끌면 안 됩니다. 숨김 파일 `.gitignore`도 올리려면 Finder에서 Cmd+Shift+. 로 숨김 파일을 먼저 표시하세요.) 파일은 92개라 한 번에 올라갑니다 (GitHub 웹 업로드는 한 번에 100개까지).
4. 아래쪽 **Commit changes**를 누릅니다.
5. **Settings → Pages → Branch: main / (root) → Save**. 1~2분 뒤 주소가 나타납니다.

## 사용 순서 (PDF → EPUB)
1. PDF를 선택하고 옵션을 정한 뒤 **변환 시작**을 누릅니다. 진행률과 남은 시간이 표시됩니다.
2. **검토 및 수정** 화면에서 쪽을 넘기며 확인합니다. 왼쪽은 원본 쪽, 오른쪽은 인식된 글입니다. 노란 글자는 인식이 불확실한 단어입니다. "다음 확인 필요 쪽" 버튼으로 바로 이동할 수 있습니다.
3. 인식이 나쁜 쪽은 **이 쪽 다시 인식 (기울기 재시도)** 버튼을 눌러 보세요. 그 쪽만 작은 각도(-2°~+2°)로 돌려 다시 읽고 가장 믿을 만한 결과를 고릅니다.
4. 책 제목·저자를 입력하고 **EPUB 만들기**를 누릅니다.

## 알아 두세요 (한계)
- **기울기 재시도의 효과**: 예시 책 3쪽을 정답과 비교했을 때 평균 일치도가 약 9~18% 좋아졌습니다(쪽에 따라 변화 없음~크게 개선). 대신 그 쪽은 4~5배 느립니다. 그래서 전체 옵션은 기본 꺼짐이고, 문제 있는 쪽에만 버튼으로 쓰는 것을 권합니다. 곡선으로 휜 글씨나 사진 위 글씨는 재시도해도 한계가 있습니다.
- **OCR 정확도는 원본에 크게 좌우됩니다.** 흰 바탕의 깨끗한 인쇄 글자는 잘 읽지만, 사진 위에 얹힌 기울어진 글자는 많이 틀립니다. 그런 쪽은 "쪽 이미지"로 두세요. ("OCR 신뢰도가 낮은 쪽은 자동으로 쪽 이미지로" 옵션을 켤 수 있습니다.)
- 2단 편집 논문, 수식, 표는 글로 정확히 옮기지 못합니다. 그런 쪽은 "쪽 이미지"를 권합니다.
- 쪽 이미지는 480×800 화면에서 작게 보입니다. 작은 글자는 "960×1600" 옵션을 쓰세요.
- **큰 PDF**: 최대 **5GB**, 최대 5000쪽까지 열 수 있습니다. 50MB를 넘으면 경고 후 진행합니다. 파일을 통째로 메모리에 올리지 않고 필요한 부분만 읽으며, 25쪽마다 PDF 연결을, 100쪽마다 OCR 엔진을 새로 열어 메모리를 비웁니다.
- **무거운 파일 팁**: PC·맥북에서 하고, 변환 중에는 탭을 열어 두세요(화면이 꺼지지 않게 요청하지만 기기에 따라 안 될 수 있습니다). 한 번에 다 하지 말고 **시작 쪽~끝 쪽**으로 나눠 변환하면 더 안정적입니다. OCR은 쪽당 약 1.5~2초이므로 3000쪽이면 1시간 반 정도 걸립니다. EPUB에 넣는 이미지 합계가 1GB를 넘으면 안전하게 중단하니, 그때는 이미지 크기를 480×800으로 하거나 범위를 나눠 주세요.
- 한국어 문자 매핑(cmaps)만 내장했습니다. 글꼴이 PDF에 들어 있지 않은 일본어·중국어 PDF는 글자 추출이 깨질 수 있습니다.
- 아직 **실제 X4 Pro 기기에서의 확인은 하지 않았습니다.** (Chromium 브라우저에서만 자동 시험했습니다.)
- 휴대폰은 메모리가 적어 큰 PDF에서 느리거나 멈출 수 있습니다. 큰 PDF는 PC/맥북을 권합니다. 5GB까지의 대용량은 합성 시험 파일로만 확인했고, 실제 수천 쪽짜리 5GB PDF를 끝까지 변환해 보지는 못했습니다.

## 보안 설계
- `connect-src 'none'`: 브라우저가 외부 서버로 어떤 데이터도 보내지 못합니다. CSP는 `default-src 'self'; script-src 'self'; style-src 'self'; ...` 그대로이며 **완화하지 않았습니다.**
- 모든 라이브러리(pdf.js, Tesseract.js, JSZip, 한·영 인식 데이터)는 `vendor/`에 내장되어 있고 외부 CDN을 쓰지 않습니다.
- PDF·OCR에서 나온 글은 `textContent`/`createTextNode`로만 화면에 넣습니다 (`innerHTML` 사용 없음). EPUB에는 XML 특수문자를 이스케이프하고 금지 문자를 제거해 넣습니다.
- 파일 크기(PDF 5GB·TXT 50MB)·쪽수(5000)·쪽 한 장의 픽셀 수·EPUB 이미지 합계(1GB) 상한, 다운로드 파일명 정제, `.gitignore` 적용.
